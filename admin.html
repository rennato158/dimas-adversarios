Base online (Firebase)

Como criar a base no Firebase (uma única vez)
  1. Em console.firebase.google.com, crie um projeto (o Google Analytics pode ficar desligado).
  2. Criação > Firestore Database > Criar banco de dados, modo de produção, região southamerica-east1.
  3. Criação > Authentication > Método de login: ative E-mail/senha. Na aba Usuários, adicione o seu e-mail e uma senha.
  4. No Firestore, aba Regras, cole as regras abaixo trocando o e-mail pelo seu e publique.
  5. Configurações do projeto > Seus apps > Web (</>): registre o app e copie projectId e apiKey para os campos acima.
  6. Aperte Conectar e entrar e depois Atualizar app para enviar a base pela primeira vez.
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    function admin() {
      return request.auth != null && request.auth.token.email in ['SEU-EMAIL@exemplo.com'];
    }
    match /dimas/publicado { allow read: if true;    allow write: if admin(); }
    match /dimas/rascunho  { allow read, write: if admin(); }
  }
}
